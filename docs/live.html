Run it on your own repo

npm i -g @testmuai/kane-cli
kane-cli login --username <u> --access-key <k>
git clone https://github.com/BenCoy09/culprit && cd culprit
bash gate0.sh      # author the test once, then prove replay is stable
bash run-demo.sh   # bisect, revert, re-verify, linear baseline

This page cannot run Kane for you: it needs a logged-in Kane CLI and Chrome on your machine. That is why the run above is a recording, labelled as one.
